カウントアップ＆ダウン

出来事や予定を「名前」と「日付」で登録するだけ。過ぎた日は経過日数を数え上げ、これからの日は残り日数を数え下げます。ログインは要りません。ID を決めれば自分だけの一覧に、ID なしなら共有ボードに登録できます。

ID で使う ID なしで使う（共有ボード）

2つの数え方

カウントアップ

日付が今日より前なら、その日からの経過日数を数え上げます。週数と周年もあわせて出るので、設立日や継続日数の確認に使えます。

カウントダウン

日付が今日より後なら、その日までの残り日数を数え下げます。7日以内になると「もうすぐ」の印が付きます。締切や発表会までの日数が一目で分かります。

当日は「本日」

日付が今日なら「本日」と表示し、今日が終わるまでの残り時間を秒まで刻みます。予定と出来事は自動で振り分けられるので、登録後の操作は要りません。

使うときの注意

ID で使う

登録したものは、その ID の一覧にだけ出ます。ID に合言葉はなく、ID を知っている人は誰でも開いて編集できます。人と同じ ID は使わないでください。メールアドレスを登録すると（任意）、通知をオンにしたカウントダウンの残り日数が毎日0時ごろにメールで届きます。アドレスは暗号化して保存するので、管理者が目にすることはありません。

ID なしで使う

誰でも登録・編集・削除できる共有ボードに登録します。他の人が登録した内容も操作できてしまうため、消えて困るものは登録しないでください。

書かないもの

誰でも使える公開のアプリです。本名や学籍番号など、本人が分かるものは ID にも登録内容にも書かないでください。
