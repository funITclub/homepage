お知らせを見逃さないために（おすすめ）

  1. スマートフォンにアプリを入れる 「Google Classroom」と「Google Chat」のアプリを入れ、大学のアカウントで ログインします。私用の Google アカウントも使っている場合は、アプリの右上のアイコンから 大学のアカウントを追加して切り替えます。
  2. アプリの通知を許可する スマートフォンの設定で、Classroom と Chat の通知をオンにします。 初めて開いたときに通知の許可を聞かれたら「許可」を選びます。
  3. Classroom の通知をオンのままにする Classroom のアプリの「設定」→「通知」で、クラブのクラスの通知をオンにしておきます。 課題や資料、クラスへの投稿が届きます。
    4. {% if club_chat %}
  4. お知らせのスペースは「すべて通知」にする Chat でクラブのお知らせのスペースを開き、スペース名 →「通知」で、すべての投稿を 通知する設定にします。運営・各 WG・メンバーからのお知らせが届きます。 WG に参加したら、WG のスペースも同じようにしておくと便利です。
    5. {% endif %}
